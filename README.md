Dompet Keluarga — a household budget site for a fictional Indonesian family of four in Jakarta. The overview dashboard shows November 2026 income (Rp 18.500.000), spending, savings, and remaining budget with a category donut and budget-vs-actual bars; Transactions lets you add, edit, delete, filter, search, and sort ~45 seeded transactions across October–November 2026, with every total updating live; Budgets tracks ten monthly categories against their limits; Bills & recurring lists nine November bills with paid toggles; Savings goals tracks four goals with add-funds controls; Reports compares October and November with the site's own SVG charts; Methods & sources explains how every figure is computed and states that the data is a fictional example. Static files only — no network requests, no build step — and it works on desktop and phone.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a browser.
